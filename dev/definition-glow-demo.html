分人状态光带 · 合成演示

合成数据，非真实人物：下面每个场景使用一张不同的虚构本命盘和一段编排好的行运序列，四种样式出自不同场景，不是同一个人的真实计算。状态条由正式代码 stateAt → calculateTimeline 计算，与本命最终分人数相同的时段不绘制，但仍可在下方条件查询中查到。

A 是最初的形态，保留在这里只作对照；B 是最终采用并已写进正式 timeline.css 的一版（选定的 Warp 参数 + 弧形白纹）。B 的纹理由真实 Warp shader 渲染：正式时间轴用 scripts/build-definition-warp-texture.mjs 离线生成一张静态 PNG，下面的面板则在本页里用同一个 shader、同一份参数现场重画。

这两条都不是 A，也不写死：两条都使用下方面板里的当前 Warp 纹理和当前全部外观值（模糊 / 亮度 / 饱和度 / 柔光 / 纹理大小 / 发光位置），所以两边的颜色、亮度、周期完全一致；唯一的差别是右侧保留了正式样式里的弧形白纹（ellipse 150% 260% at 0% 130%，白 20%，周期 211px），左侧把它关掉。这层白纹由共享标记 definition-bars.js 统一加在一分人实体条上，是独立的清晰层：它自己不模糊，也不改变数字所在的层；短事件标记不带它。A 自己已经用背景层画了这条白纹，所以 A 的标记层被关掉，不会叠出第二层。
