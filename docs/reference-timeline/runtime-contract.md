# 运行、计算与缓存契约

## 启动和回退

在本工作区运行 `npm run dev -- --host 127.0.0.1 --port 5186` 查看开发版；运行 `npm run build:pages`、`npm run preview -- --host 127.0.0.1 --port 5187` 查看静态构建；本机包用 `npm run build:desktop` 构建。`npm test` 是单元与本地服务测试，浏览器测试需在预览服务运行时设置 `E2E_URL`。`scripts/generate-transit-events.mjs` 默认只生成 2026 年，`--all` 才生成 2021–2036 年；`scripts/verify-transit-events.mjs --all` 逐年校验。

所有阶段提交都在 `feature/reference-timeline-v1`。回到固定基线可用 `git switch --detach 14ae78a8a3c086138812f7c9879acbd68c54cf86` 在另一个工作区查看；当前工作区的任何切换应先检查状态。正式安装和原 `main` 不依赖本分支，无需生产数据回滚。

## 引擎能力与精度

- 公共年度文件保存 13 个行运点在 UTC 年初的闸门、爻线，以及逐点变化事件。文件带计算签名，manifest 记录文件字节数和 SHA-256；不含出生、账户或人物信息。
- 生成器每 60 秒比较离散状态，再把已观察到的边界收敛到 1000 毫秒。这是事件边界的扫描容差，不是星历绝对精度证明。同一分钟内某点离开又回到相同闸门和爻线仍可能漏记。
- 同一瞬时多个点的变化先合并，再计算通道与中心。一个点离开不会清除其他点或出生盘贡献。闸门未变的爻线变化保留在年度文件中，但上一／下一闸门导航只使用闸门变化。
- 该离散索引无法恢复连续黄经、速度、Color、Tone、Base 等字段。图表瞬时状态及仍需连续字段的原有详情继续调用固定引擎，不从事件表猜值。
- 出生盘输入当前接受 `HH:MM`；真实秒值明确拒绝，不静默截断。`timeUnknown` 使用约定的 12:00 计算，同时在返回对象与缓存键中保留未知标记。

## 缓存与失败路径

- manifest 每次首次请求用 `no-cache`；签名和内容哈希写入的年度文件用 `force-cache`。同一年度并发请求合并。内存年度缓存最多 3 年且按实际编码字节数不超过 1,000,000 字节，按最近使用淘汰；浏览器 HTTP 缓存另由浏览器管理。
- 文件缺失、网络失败、长度、哈希、结构或签名错误时，该年不进入有效缓存。Worker 只对用户请求中缺失的片段调用原计算；结果保留来源标记和可见提示。取消 Worker 不把未完成结果写入派生缓存。
- 出生盘缓存在当前应用进程内，最多 8 项。键包含固定引擎版本、小时适配规则、出生日期、有效分钟时刻、有效时区和未知时刻标记；姓名、语言和主题不在键中。当前引擎返回对象可用 JSON 或 `structuredClone` 保留 `gate/line/color/tone/base/longitude`；缓存本身不跨重启持久化，也不接入公共年度文件。
- 派生时间轴最多保留 4 份，键含请求范围、出生盘身份、模式和行星。筛选仅处理已完成的派生区间。语言、主题、弹窗操作不重新生成年度数据。人物原始资料仍由既有本地／账户路径保存，清除这些临时缓存不会删除人物。

这些限制与命令只用于内部实施和验收，不增加前端说明页。
