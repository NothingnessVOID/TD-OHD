# 阶段 1：共享详情与轻量资料库

依据：交接包主规格第 3 节，验收清单 A、B 组。此阶段保留原版弹窗位置和资料文字，资料库可无出生盘独立使用。

## 已完成

- 闸门、通道和中心的静态正文由 `reference-content.js` 提供；弹窗与资料库调用同一来源。闸门保留人类图、易经、基因钥匙切换，六爻在闸门内查看，当前激活爻有标记。
- 目录覆盖 9 中心、36 通道、64 闸门；爻线不占顶层列表。搜索 `14.2`、反向通道 `60-3` 和不同横线形式可定位。回路组及子回路归在“回路”，整合通道出现在个体相关分组，不新增独立“network”类别。
- 弹窗展示闸门的全部关联通道，未完整通道仍可打开；中心也可进入未完整通道。零完整通道时继续显示悬挂闸门，不提前返回。行星点击保留侧、行星、爻线的选中上下文。
- 资料深链接只使用 `#library/...`，进入资料库会清除当前地址里的出生参数。已有人物仍在内存中，返回原图无需重算或删除。
