# 阶段 4：闸门变化导航与爻线展开

## 实际修改

- 闸门行可展开其六条爻线；爻线与所属闸门共用时间位置，避免成为顶层平行列表。
- 时间轴上方常驻上一／下一闸门变化按钮；左右键执行同一导航，上下键保留逐分钟移动。定位时同步时间轴行、选中时刻与身体图闸门高亮。
- 回退扫描也记录闸门与爻线事件。阶段 5 将独立验证高级设置中的条件筛选；筛选控件的基础结构随本次时间轴界面接入。
