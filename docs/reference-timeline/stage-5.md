# 阶段 5：对象状态与桥接筛选

## 实际修改

- 以时间轴已推导区间执行闸门、爻线、通道、中心的激活／未激活查询。单行多个目标按“任一”匹配，条件行之间可选“全部／任一”；结果按 `[start, end)` 返回并合并相邻等价区间。
- 桥接按固定本命中心岛编号计算，允许新出现的中间中心连接原有岛。二分、三分、四分及无适用岛均有测试；桥接状态中的“未激活”现按补集查询。
- 查询使用当前人物的出生盘、图表模式、行星范围和已计算窗口；非法目标明确报错，不生成貌似有效的结果。
