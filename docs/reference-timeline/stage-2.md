# 阶段 2：2026 年公共行运事件试验

## 修改与回退点

- 固定 NatalEngine 1.6.0、astronomy-engine 2.1.19、时间适配器和年度算法的计算签名。
- 以 13 个公共行运点生成 2026 年年初状态与闸门、爻线变化；事件边界细化到 1000 毫秒。
- 年度文件不含人物、出生盘或账户数据。此提交只放入 2026 年文件；后续年度文件属于阶段 3。

## 试验与验证

| 项目 | 实测结果 |
|---|---|
| 2026 年生成 | 约 36.6 秒；结束时 RSS 约 159 MB，未测峰值。 |
| 文件 | 198,931 字节；gzip 53,835 字节；brotli 34,875 字节。 |
| 事件 | 闸门 1,189；爻线 5,966；合计 7,155。 |
| SHA-256 | `c86ace5bada03fc3019ad22bab71f518f22c2cf9893e45f7fc38f2c01af46c47`。 |
| 同引擎对照 | `node scripts/verify-transit-events.mjs 2026`：20,506 个抽样时刻，差异 0；覆盖边界前后、逆行和年末。 |
| 跨时区 | 默认本地环境与 `TZ=Asia/Shanghai` 重新生成的核心数据逐字节相同。 |

## 预览、已知问题和未验证项

本阶段仅交付可复算的公共数据，无新增界面；桌面和手机预览沿用阶段 1。按一分钟离散扫描识别变化，若同一行运点在一分钟内往返到相同闸门与爻线，扫描可能漏记；同引擎抽样验证不能证明连续时间上的绝对完备。尚未测量生成过程的峰值内存及物理手机表现。后续阶段以此提交为可回退点。
