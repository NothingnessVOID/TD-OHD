# P0 集成预览：先由用户验收

状态：A/B/C 已集成，按用户最新要求，本阶段只进行必要构建和明显错误检查。完整自动化测试、冒烟及全量浏览器回归等待用户确认方向和功能后再进行。本文件不表示已完成正式发布验收。

## 本次可体验内容

1. **人物完整编辑**：姓名、日期、时间、未知时间、地点/时区；保留原人物ID与创建时间，更新后相关视图刷新，失败时保留输入。
2. **Team/Penta工作区**：直接从已有资料勾选3–5人分析；桌面左侧紧凑选人和Penta图，右侧持续阅读概览、通道、闸门和贡献；手机自然纵向。高级多团队/多Penta管理继续保留。
3. **共享详情**：出生图、资料库及Penta复用普通闸门/通道正文；Penta来源显式传入，估算时间有标记，缺少合格专项正文就不显示空模块。
4. **集成接线**：Team接入`pentaDetailAdapter`；当前人物删除、失效或新建时调用`clearCurrentChart()`；新建Penta使用局域网兼容UUID。
5. **LAN兼容**：年度缓存保留完整SHA-256、签名与结构验证，非安全HTTP环境使用固定版本的noble回退；人物编辑弹窗补齐键盘焦点约束。

## 建议用户先看

- 选一位虚构人物编辑出生资料，切换“未知时间”，观察提示和其他视图是否符合使用习惯。
- 直接选3位人物生成Penta，重点看左图右文的布局、选人步骤和手机阅读顺序。
- 查看闸门/通道的成员激活与四个阅读栏目，确认信息层次、术语及切换体验。

这些是体验建议，不要求用户替代后续完整技术测试。
