# 未来发布路线，尚未选择

| 维度 | A：兼容 AGPL 的公开发行 | B：原创 MIT，替换 astronomy layer | C：取得适用商业授权 |
| --- | --- | --- | --- |
| Modern | 保留当前 AGPL 端口和修复，准备适用的组合许可、对应源码和 notices | 替换 AGPL C# astronomy port；选择权利清楚的数据，并复验全部精度与时间尺度 | Astrodienst 授权之外，还需 CReizner 对 C# 端口及其贡献权利的许可；或使用被商业授权覆盖的 C 实现替换 |
| Jovian | 保留历史 C，核定 GPL 后续版本选择和组合关系，提供所需源码；DE406 数据范围确认 | wrapper 可独立 MIT；若要求 MIT 组合，需替换历史 GPL 核心及相应数据。精确历史兼容成本很高 | 取得明确覆盖 Swiss 1.76、历史镜像压缩数据及目标发布方式的合同 |
| 可公开部署？ | 条件满足后可；当前审计不认证已满足 | 替换和许可完成、回归通过后可 | 所有权利人授权、合同条件满足后可 |
| 原创可保持 MIT？ | 原创子文件可以 MIT；整个组合不能因子文件 MIT 而跳过 AGPL 条件 | 原创可 MIT；继承 MIT/OFL 等各自保留 | 原创可选 MIT；第三方库与数据仍各有许可 |
| 要替换什么？ | 通常无需替换算法；补全发布和授权材料 | Modern astronomy implementation 与受限数据；Jovian 历史核心和数据若要求 permissive 组合 | 如果 C# port 商业授权拿不到，Modern 需改用合同覆盖的实现 |
| 工程成本 | 低至中：notice、source archive、可复现构建和发布流程 | 高：完整精度、跨年代、边界、时间语义、WASM 和历史兼容回归 | 授权可得时低至中；必须换 Modern runtime 时中至高 |
| 主要未知点 | 完整组合边界、原始资料权利、对应源码的有效路径、历史数据条款 | 替代引擎精度和历史一致性、原始数据权利、独立实现是否受到原作限制 | 端口是否可另授、历史版本/数据是否覆盖、贡献权利链和合同范围 |

成本为工作类别估计，没有给出不可验证的工时或价格承诺。本轮禁止改变计算结果，因此 B/C 的实际 astronomy 替换只能在后续授权任务中进行。

当前 [Professional 合同（September 2026）](https://www.astro.com/swisseph/secont_e_2609.pdf)覆盖 C source 和专有压缩数据；规定六年有效期，第三方业务 API 使用方需另获授权。公开源码中的修改另有条款，必须阅读实际签订版本。当前网页合同不能替代已经签署的合同，也不能代表 CReizner 的许可。旧 PDF 地址失效，需要按新链接咨询和核对。

下一步由用户决定发布目标：整个产品接受 copyleft，或只将独立原创部分 MIT 并替换天文层，或申请覆盖所有相关权利人的商业授权。选择之前保持现有边界和冻结生产变更。
