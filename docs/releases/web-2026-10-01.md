# 2026-10-01 网页更新：本命引擎与外观

本次更新的发布目标是 [TD-OHD 官方 Netlify 网页版](https://td-ohd.netlify.app/)。[GitHub Pages](https://nothingnessvoid.github.io/TD-OHD/) 是独立发布的旧版本，尚未同步本次更新。此文说明本次源码与发布范围；是否已上线应以正式部署的结果为准。

## 本命引擎迁移

本命计算切换为 **SharpAstrology.HumanDesign 1.2.0 + SharpAstrology.SwissEph 0.5.1 + 文件型 Swiss Ephemeris**，通过 .NET 10 浏览器 WebAssembly 在使用者浏览器内运行。设计时刻由 SharpAstrology 按太阳黄经回推 88 度计算；出生时刻先按输入的时区偏移转换为 UTC。出生时间未知时仍采用中午 12:00。

本命计算、出生时间敏感性复算，以及关系／团队分析所需的各个人本命输入经过新的本命引擎接口。**行运和行运时间轴继续使用 NatalEngine 1.6.0**；Gene Keys、图形数据和部分解读／结果适配也仍使用它。此次迁移有明确的本命范围，不代表全部引擎替换，也不宣称已完成独立的天文精度认证。

首次计算会按需加载本站的 WASM 运行时与星历文件。连接较慢时首次等待会更长；没有下载完成或文件不可用时会显示计算失败。Swiss 文件模式已禁用 Moshier 回退，缺失数据时不会静默改用另一套星历。

## 星历覆盖与当前边界

本次构建打包 `sepl_18.se1` 与 `semo_18.se1`，文件覆盖 **1800—2399 年**。来源固定到 Swiss Ephemeris 仓库提交 `3186eed405bd2b4ff520c91d0b27bb25e9d75106`，构建时逐个核验 SHA-256；完整记录见[星历清单](../../engine-wasm/ephemeris-manifest.json)。

上述年份说明随构建提供的星历文件覆盖情况。本次迁移不另行定义产品日期范围，也不将静态代码检查等同于完整历史范围的运行验证。跨数据块、历史时区和边界日期仍需专门验证；所需文件不可用时，当前文件型路径会报错。

## 外观与本命四箭头

“更多”菜单集中提供分享、语言、主题与皮肤设置。Classic／Chakra 两种预设只改变能量中心配色；强调色、意识色、设计色、行运色、图表背景和闸门字号六项设置全局共用，切换预设及明暗主题继续生效，并保存在当前网站的浏览器本地存储中。

闸门字号默认 22 个 SVG 单位，可调范围为 14—30。来源高亮采用圆圈。行运来源色更新为 `#1af4ff`；时间轴轨道色由 75% 的行运色与 `#445457` 混合派生，自定义行运色时同步变化。

本命人体图显示四箭头：左上摄取、左下环境使用设计侧来源色，右上动机、右下视角使用意识侧来源色。方向读取计算结果的 `arrow`，缺少方向时由有效 Tone 推导 L／R，不从四箭头简写猜测。行运图、关系合图不附加本命四箭头。这些变更属于显示与交互，不修改计算参数。

## 隐私与本地构建

静态网页版在浏览器内计算，保存的人物资料留在当前网址的浏览器本地存储中。首次加载会向本站请求运行时和星历资源，出生资料不会作为这些资源请求的查询参数发送。图表分享链接包含出生资料，分享时应留意链接内容。Netlify 与 GitHub Pages 使用不同站点存储；本次发布不会把本机 SQLite 数据库、密码、备份或个人记录上传到网站。

本地构建需要 Node.js 20+ 与 .NET 10 SDK；`dev`、`build`、`build:pages`、`build:desktop` 均先执行 `build:engine`。首次构建会从固定上游快照获取星历并校验；后续构建复用通过校验的文件。本机桌面服务是独立运行方式，网页发布不等于替换使用者正在运行的本机安装。
