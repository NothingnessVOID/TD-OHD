字体来源、许可与恢复方法

本站自托管 LXGW Neo ZhiSong（霞鹜新致宋）标准版 v1.067，作者 lxgw，衍生于 IPAex Mincho 和 IPAmj Mincho。本站的 WOFF2 子集与原字体均按 IPA Font License 1.0（日英全文）提供。另附上游许可证。字体不安装到操作系统。

恢复 IPA 原始授权字体

在应用的字体设置中选择“IPA 原始字体”（ipa），即可停止使用霞鹜新致宋并按需加载本站保留的原始 IPAmjMincho 006.01。此文件来自官方页面指定的发布渠道，未对子集、字形、内部名称或字体二进制做任何修改。CSS family “TD IPA Original”只是网页引用别名。原始字体采用日文字形，部分新增中文字可能仍使用回退字体。

“原有字体”（original）为应用原有字体栈，与恢复 IPA 原始字体是两个不同选项。恢复 IPA 无需安装系统字体。管理员集成时须保留可用的 IPA 切换入口，不能仅用系统字体代替。

源字体与可重复构建

本站分包只提供汉字与标点，ASCII、拉丁字母、数字及易经等图表符号继续由原有字体栈显示。全量源 TTF 不参与初始字体加载，用户可自行下载并继续修改。WOFF2 子集沿用 IPA Font License 1.0。
